# **📦 视频重命名脚本说明文档（支持 rclone 网盘）**

该脚本通过 rclone 操作网盘中的文件，实现批量重命名电视剧/电影文件，统一命名风格，便于媒体服务器识别（如 Jellyfin / Plex）。

支持字幕、视频、.nfo 等格式；支持跳过已标准化文件；支持并发与 DRY_RUN 模拟模式。

---

## **🎯 功能概览**

| **功能项** | **描述** |
| --- | --- |
| 支持媒体类型 | 电视剧（tv）、电影（movie） |
| 支持格式 | 视频、字幕、.nfo（详见下表） |
| 文件名标准化 | 自动根据目录结构、集数、片名重命名 |
| 智能跳过判断 | 如果文件名已规范，自动跳过 |
| 多线程支持 | 每个文件夹并发处理，线程数可配置 |
| DRY_RUN 模拟模式 | 可只打印命令不执行，便于测试 |
| rclone 支持 | 基于 rclone moveto，不移动整个目录 |

## **📁 支持的文件扩展名**

| **类型** | **扩展名** |
| --- | --- |
| 视频 | .mp4, .mkv, .avi, .mov, .flv, .wmv, .webm, .ts, .rmvb, .3gp, .iso, … |
| 字幕 | .srt, .ass, .ssa, .sub, .vtt, .pgs, .smi, .txt, … |
| 信息类 | .nfo |

## **📂 支持的路径结构**

### **电视剧（tv）**

```
tv/<剧名>/<Season X 或 SXX>/<文件名>
```

✅ 示例：

```
tv/权力的游戏/Season 1/001.mp4
tv/Better Call Saul/S02/第02话 嫌疑.mp4
```

---

### **电影（movie）**

```
movie/<电影文件夹>/<文件名>
```

✅ 示例：

```
movie/阿凡达 Avatar (2009)/阿凡达 高清版.mkv
movie/邀请函 sd/邀请函 The Invitation 1080p.srt
```

---

## **🔄 文件重命名规则**

### **电视剧文件命名规则**

> 自动识别集数 + 提取剧名 + season 号重命名
> 

| **条件** | **示例文件名** | **提取结果** | **新文件名格式** |
| --- | --- | --- | --- |
| 数字前缀 | 001.mp4 | E001 | 剧名.S01E0001.mp4 |
| 数字+下划线标题 | 002_嫌疑人.mkv | E002, 嫌疑人 | 剧名.S01E0002.嫌疑人.mkv |
| 中文“第x话”标题 | 第3话 出走.avi | E003, 出走 | 剧名.S01E0003.出走.avi |
| E标识 | S02E05.mp4 | E005 | 剧名.S02E0005.mp4 |

---

### **电影文件命名规则**

> 若文件名
> 
> 
> **不符合标准化前缀规则**
> 

```
<文件夹名>.<扩展名>
```

✅ 示例：

```
movie/阿凡达 Avatar (2009)/高清最终版.mkv
→ 阿凡达 Avatar (2009).mkv
```

## **🛑 跳过重命名的情况（电影部分）**

| **跳过条件编号** | **条件描述** | **示例文件名** |
| --- | --- | --- |
| ✅ 1 | 文件名与文件夹名完全一致 | 阿凡达 Avatar/阿凡达 Avatar.mkv |
| ✅ 2 | 文件名以目录名为前缀（忽略分隔符） | 阿凡达 Avatar/阿凡达.Avatar.2009.1080p.mkv |
| ✅ 3 | 文件名以目录中第一个 [] () 【】 括号中的标题为前缀（忽略分隔符） | 阿凡达 Avatar【Avatar】/Avatar.1080p.srt |
| ✅ 4 | 文件名以主标题为前缀（宽松匹配，忽略空格与符号） | 邀请函 sd/邀请函 The Invitation 1080p.mkv |

## **💡 示例：是否会被重命名？**

| **目录名** | **文件名** | **是否跳过** | **说明** |
| --- | --- | --- | --- |
| 邀请函 sd | 邀请函 The Invitation 1080p.mkv | ✅ 跳过 | 主标题“邀请函”匹配成功 |
| 邀请函 sd | The Invitation.mkv | ❌ 重命名 | 不符合主标题、括号、目录前缀匹配 |
| 星球大战 | 星球大战.中文字幕.1080p.ass | ✅ 跳过 | 文件名以目录名为前缀 |
| 星球大战【Star Wars】 | Star Wars 4K.mkv | ✅ 跳过 | 匹配括号中的 Star Wars |
| 疯狂动物城 | 狂野都市 Zootopia 1080p.mkv | ❌ 重命名 | 文件名与目录名无关 |

## **⚙️ 使用方法**

运行命令：

```
python3 rename_rclone_videos.py
```

如果只是想测试重命名命令是否正确，不实际改名：

```
DRY_RUN = True
```
