# **📦 视频重命名脚本说明文档（支持 rclone 网盘）**

该脚本通过 `rclone` 操作网盘中的文件，实现批量重命名电视剧/电影文件，统一命名风格，便于媒体服务器（如 Jellyfin / Plex / Emby）识别。

支持 **并发处理**、**智能识别**（SxxEyy / 1x01 / 第x集）、**合集保护**、以及 **Dry Run** 模拟模式。

---

## **🎯 功能概览**

| **功能项** | **描述** |
| --- | --- |
| **支持媒体类型** | 电视剧（tv）、电影（movie） |
| **支持格式** | 视频（mp4/mkv...）、字幕（srt/ass...）、nfo |
| **文件名标准化** | 自动根据目录结构、集数、片名、季号进行标准化重命名 |
| **智能集数识别** | 支持 `S01E02`, `1x02`, `Ep.2`, `第2集`, `Episode 2` 等多种格式 |
| **合集保护** | **电影合集**（单文件夹含多部电影）自动跳过重命名，防止覆盖 |
| **元数据清理** | 自动移除文件名中的冗余信息（如 `[1080p]`, `(H.265)`, `第 x 集`） |
| **格式规范化** | 电影文件重命名强制使用 **点分隔符** (`.mp4`)，消除空格 |
| **多线程加速** | 默认开启 16 线程 (`MAX_WORKERS = 16`) 并发处理，极大提升速度 |
| **模拟模式** | `DRY_RUN = True` 时仅打印操作日志，不实际执行 |

## **📂 支持的路径结构**

### **电视剧（tv）**

需包含 Season 层级，支持多种命名风格：

```
tv/剧名/Season 1/001.mp4
tv/剧名/S02/第02话.mp4
tv/剧名/第 1 季 - 4K/S01E01.mkv
```

### **电影（movie）**

```
movie/电影名 (2023)/电影名.mkv
movie/[电影名][2023][4K]/原有文件名.mkv
```

## **🔄 核心重命名规则**

### **📺 电视剧 (TV)**

脚本会提取文件的 **季号 (Season)** 和 **集号 (Episode)**，并按以下标准格式重命名：

`文件夹名.SxxEyy.标题.后缀`

**智能处理：**
1. **自动补全**：如果文件名只有 `01.mp4`，自动根据文件夹推断 Season，命名为 `Call Saul.S02E001.mp4`。
2. **冗余清除**：如果文件名已包含 `S01E02`，会自动移除 `第 2 集`、`Episode 2` 等冗余文字。
3. **中文支持**：支持识别 `第 x 话`、`第 x 集`。

| **原始文件名** | **识别结果** | **新文件名 (示例)** |
| --- | --- | --- |
| `001.mp4` | S1, E1 | `Better Call Saul.S01E0001.mp4` |
| `S02E05.mp4` | S2, E5 | `Better Call Saul.S02E0005.mp4` |
| `1x02.mkv` | S1, E2 | `Better Call Saul.S01E0002.mkv` |
| `S01E02 - 第 2 集.mkv` | S1, E2 | `Better Call Saul.S01E0002.mkv` (去除 "第 2 集") |
| `[Group] Title - 03.mp4` | S1, E3 | `Better Call Saul.S01E0003.Title.mp4` |

### **🎬 电影 (Movie)**

`文件夹名.后缀` (强制点分隔)

**增强逻辑：**
1. **括号提取**：如果文件夹是 `[阿凡达][2009]...`，会自动提取 `阿凡达` 作为文件名，而不是整个长文件夹名。
2. **合集跳过**：如果一个文件夹内有 **2 个以上视频文件**（如《功夫熊猫 1-4》），脚本会 **跳过重命名**，防止将所有文件都改成同一个名字。
3. **格式清理**：重命名时将空格替换为 `.`，如 `Kung Fu Panda.mkv` -> `Kung.Fu.Panda.mkv`。

| **文件夹名** | **处理逻辑** | **新文件名** |
| --- | --- | --- |
| `Avatar (2009)` | 标准模式 | `Avatar (2009).mkv` |
| `[Avatar][2009][1080p]` | 提取首个括号内容 | `Avatar.mkv` |
| `Kung Fu Panda Collection` | 含多部电影 | **⛔ 跳过** (保留原文件名) |

---

## **🛑 智能跳过规则**

为了防止重复操作或误操作，以下情况会自动跳过：

1. **文件名已规范**：文件名与目录名一致（或仅有分隔符差异）。
2. **文件名包含目录名**：文件名以目录名为前缀（如 `Avatar` 文件夹中有 `Avatar.1080p.mkv`）。
3. **合集保护**：电影文件夹内包含多个视频文件。
4. **无法识别集数**：TV 模式下无法从文件名提取集数。

## **⚙️ 配置与运行**

### **1. 配置路径 (rename_rclone_videos.py)**

修改脚本顶部的 `REMOTES` 配置网盘路径：

```python
REMOTES = {
    'quark': {
        'tv': ['quark/tv'],       # 你的 rclone 路径
        'movie': ['quark/movie']
    },
    'aliyundrive': {
        'tv': ['media/tv'],
        'movie': ['media/movie']
    }
}
```

### **2. 运行脚本**

```bash
# 建议先开启 DRY_RUN = True 进行模拟
python3 rename_rclone_videos.py
```

### **3. 性能设置**

脚本默认开启多线程 (`MAX_WORKERS = 16`)。如遇 API 限制，可调低该值。
